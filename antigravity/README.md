# Kin for Antigravity

Kin connects your accounts at about 90 services, including GitHub, Notion, Linear, Jira and Confluence, Asana, Sentry and Airtable. You can connect two accounts of one service, such as a work and a personal GitHub. Each account has its own rule per action: Allow, Ask me or Block. Kin checks the rule on its server when the action runs. Changes set to Ask me wait for your approval, including on your phone. Every attempt goes in one Activity log.

## Setup

1. Install the plugin: `git clone https://github.com/kinlab-ai/kin-plugin` then `agy plugin install kin-plugin/antigravity`.
2. In Antigravity, open Agent settings, then Customizations, and select Authenticate next to `kin_kin`.
3. Sign in to Kin in the browser. Create a Kin account if you do not have one.
4. Connect your services in Kin at https://app.kinlab.ai.

## Try

- List my open issues on my work GitHub.
- What is open in my work Linear?
- Create a Linear issue titled Fix signup redirect and wait for my approval.
